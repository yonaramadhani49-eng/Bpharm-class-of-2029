BPharm One — Class of 2029

DEPLOYMENT
1. Upload index.html, style.css and app.js to the ROOT of the GitHub Pages repository.
2. In Supabase SQL Editor, run supabase-storage-policies.sql.
3. Make sure Storage buckets named memories and cards exist.
4. GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root).

The browser uses the Supabase publishable key. Supabase recommends publishable keys for browser apps; keep secret/service keys off the client. RLS remains responsible for access control.
